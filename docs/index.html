migguard 0.4.0 · MIT

Check the migration.
Leave the database alone.

Lint the SQL. Dry-run on a clone. Prove values moved. Hash the source file. One last line is the product.

ALL_PASS PRESERVED INCOMPLETE APPLY_FAILED

Install

git clone https://github.com/hathornwarrenprotocol-sys/migguard.git
cd migguard
python3 migguard.py --version

Commands

python3 migguard.py check file.sql --db ./app.db
python3 migguard.py check file.sql --db ./app.db \
  --table User --key id --from-col name --to-col fullName
python3 migguard.py query --db ./app.db --code-root ./app
python3 migguard.py pack --db ./app.db --code-root ./app
python3 migguard.py drift --db ./a.db --other ./b.db

Agent law

If the last line is not ALL_PASS or PRESERVED, do not apply. Never write the source file. If db_sha256 does not match the file you were given, stop.
